# SEG UNDA

Plateforme en cours de développement pour les étudiants en **Sciences Économiques et de Gestion (SEG)** de l'**Université Notre Dame d'Abidjan (UNDA)**.

## Fonctionnalités actuelles
- Formations Licence 1, Licence 2 et Licence 3
- Authentification Firebase
- Espace étudiant
- Sauvegarde du niveau
- Structure préparée pour les cours et SEG UNDA AI

## Structure
- `js/firebase.js` : configuration Firebase centralisée
- `js/header-auth.js` : authentification dans l'en-tête
- `js/courses.js` : sauvegarde du niveau
- `cours/` : ressources pédagogiques
- `ia/` : future interface SEG UNDA AI
- `backend/` : futur backend sécurisé
